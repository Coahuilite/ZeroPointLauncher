# ZeroPointLauncher

ZeroPointLauncher 是一个正在重新开发的 Minecraft 启动器项目。它希望让整合包和游戏实例更容易管理：你可以在同一套基础内容上创建不同的实例，保留自己的修改，也可以在未来将选定的配置分享给其他玩家。

项目延续原作者初夏同学关于**实例继承、共享与差异管理**的设计思路。我们会优先考虑 GT New Horizons（GTNH）等大型整合包的需求，但目标并不限于 GTNH，也包括普通整合包和玩家自己创建的实例。

> **目前仍处于早期开发阶段。** 现阶段能够运行的是实例文件管理核心及其演示程序，尚不能通过 ZeroPointLauncher 登录账号或启动 Minecraft。UI界面也尚未接入。

## 为什么要做这个项目？

玩大型整合包时，我们常常需要几套略有不同的配置：一套用于日常游玩，一套用于测试模组，或是从朋友分享的配置继续修改。直接复制整套游戏目录虽然简单，却不便于追踪差异；改动一多，也很难记清哪些文件来自整合包、哪些是自己修改的。

ZeroPointLauncher 希望把这些关系交给启动器管理。

- **从已有实例派生新实例。** 基础整合包、玩家共享的预设和个人实例都可以成为进一步修改的起点。
- **各自修改，互不干扰。** 修改子实例的配置或模组，不应改变父实例及其他子实例。
- **保留个人改动。** 重新准备实例工作区时，应当保留用户新增、修改或删除的内容。
- **按需共享差异。** 未来希望能够分享选定的配置改动，而不必每次都分发完整整合包。

这些是项目的设计方向，并不代表所有功能都已完成。特别是实例升级、差异分享和磁盘空间优化，目前尚未形成可供玩家日常使用的完整流程。

## 当前进度

目前已经完成并提供演示的部分包括：

- 解析实例之间的继承关系，并解释文件来自哪一层；
- 将实例内容复制到独立工作区；
- 识别并保留工作区中的个人修改，包括文件新增、修改和删除；
- 通过自动化测试与隔离示例验证不同实例之间的修改不会相互影响。

接下来计划逐步实现实例升级预览与冲突处理、选定修改的分享，以及 Minecraft 运行时和桌面界面的接入。

开发进度和已经验证的行为以[验收记录](docs/acceptance.md)为准。文档中提及的未来设计不等于现有功能，也不意味着已经完成跨平台验证。

## 运行当前示例

目前没有可供普通玩家使用的启动器版本。如果你想了解现阶段的实现，可以运行仓库中的文件管理演示。

需要准备 **JDK 25**，并将 `JAVA_HOME` 指向对应的 JDK。项目使用 Gradle Wrapper，无须另外安装 Gradle。

在仓库根目录运行：

**Windows（PowerShell）**

```powershell
.\gradlew.bat --no-daemon :workspace-nio:run
```

**Linux / macOS（Shell）**

```bash
bash gradlew --no-daemon :workspace-nio:run
```

示例会在新建的实验目录中派生两个实例，修改其中一个，再检查这些修改是否得到保留、是否影响另一个实例。它不会扫描或修改你已有的 Minecraft 游戏目录。

你可以参照[工作区验收指南](docs/workspace-walkthrough.md)逐项查看实验结果。首次运行需要下载 Gradle 和相关依赖。

## 参与开发

如果你对实例管理、Java 或 Minecraft 启动器开发感兴趣，欢迎阅读文档、提出问题或参与讨论。

当前项目主要分为以下几个部分：

| 目录                                 | 内容                          |
| ---------------------------------- | --------------------------- |
| [`layerfs/`](layerfs/)             | 实例继承、文件来源和差异处理的核心规则，不直接操作磁盘 |
| [`workspace-nio/`](workspace-nio/) | 工作区文件复制、扫描、状态保存与路径检查        |
| [`docs/`](docs/README.md)          | 架构设计、行为约定、运行时规划和验收说明        |
| [`tools/`](tools/)                 | 隐私检查与辅助验证工具                 |

在 Windows PowerShell 中运行测试和两个示例：

```powershell
.\gradlew.bat --no-daemon :layerfs:test :workspace-nio:test :layerfs:run :workspace-nio:run
```

Linux / macOS 下可将 `gradlew.bat` 换成 `bash gradlew`。相关平台能否作为正式发行目标，仍需以实际验收结果为准。

想进一步了解整体设计，可以从[开发文档导航](docs/README.md)开始。提交代码或分享日志前，请先阅读[分享前检查](docs/sharing.md)，避免将本机路径、账号信息或个人游戏数据带入公开仓库。
